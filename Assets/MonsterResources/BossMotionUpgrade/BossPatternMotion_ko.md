# 보스 패턴별 동작

30개 패턴 × 8방향에 준비·대기·발동·회복·연속 타격 클립을 연결했습니다. 기존 베기·강타·코어·걷기 스프라이트는 그대로 유지하고, 어깨 포 조준/반동과 양팔 시전/힘 모으기 프레임 96개를 추가했습니다.

- 베기: 칼을 들어 준비한 뒤 휘두릅니다. DoubleClaw의 두 번째 타격은 반대 흐름으로 되받아칩니다.
- 지면 공격: 자세를 낮추거나 들어 올린 뒤 내려찍습니다. 지면 강타·균열·가시·잠복의 프레임 순서와 몸의 강조 동작이 다릅니다.
- 사격: 어깨 포를 겨누고 실제 발사 이벤트마다 반동을 재생합니다. 다음 발사 전에는 조준 자세로 돌아갑니다.
- 회전: RotatingScythes·SpiralBarrage·OrbitRelease는 클립 안에서 8방향의 몸 스프라이트를 순환합니다.
- 시전: 양팔을 올리거나 코어 쪽으로 힘을 모읍니다. 중력·낙하·노바·종말 패턴에 서로 다른 프레임 흐름을 사용합니다.
- 긴 예고: 준비 동작을 마친 뒤 대기 모션을 반복합니다. 단발 공격은 실제 공격 이벤트가 도착해야 발동합니다.
- 지속 공격: 빔·공전·시전 루프는 여러 피해 이벤트가 발생해도 처음부터 재시작하지 않습니다.

AnimatorOverrideController는 보스 인스턴스마다 따로 생성됩니다. 공유 컨트롤러·프리팹·프로필·씬을 수정하지 않습니다. 클립은 SpriteRenderer.m_Sprite만 제어하고, 몸의 작은 기울기·반동은 보스의 시각 자식 오브젝트에만 적용합니다. 루트와 콜라이더·피해 수치·실제 패턴 이동은 바꾸지 않습니다. 새 패턴 클립이 누락되면 기존 모션으로 돌아가며, v1 모션 리소스도 사용할 수 있습니다.

추가 스프라이트는 기본 이미지 생성 도구로 제작했습니다. SourceSheets에 최종 원본, BossPatternMotion_Prompts.json에 생성·수정 프롬프트를 보관합니다. 게임용 PNG는 원본 픽셀의 잘라내기와 투명 여백 추가만 적용했으며 재그림·리샘플링·색 변경을 하지 않았습니다. 생성된 완전 거상 자세의 동/서 방향이 정면을 향한 두 프레임은 재생에 사용하지 않고 같은 방향의 팔 뻗기 자세를 사용합니다.

Previews/PatternMotion_Preview.gif는 포함된 스프라이트 클립을 재생한 미리보기입니다. Unity 게임 화면 녹화가 아니며 VFX와 런타임 반동은 표시하지 않습니다.

적용: Unity를 닫고 ZIP의 Assets를 프로젝트 최상위 Assets와 병합합니다. 새 모션은 기존 BossMonster가 자동 연결합니다. 에디터에서 Tools > Monster > Boss Motion Upgrade > Validate Resources로 리소스를 확인한 뒤 Play에서 실제 전투를 확인하세요.
