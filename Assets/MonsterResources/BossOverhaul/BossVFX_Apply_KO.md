# 몬스터 네온 VFX·사운드·보스 애니메이션 수정본

이전 보스 추적·고난도 수정본에 일반 몹 3종의 전투 연출, 새 무료 애니메이션 VFX, 타격 사운드, 보스 네온 표현과 바닥 연출을 추가한 전체 Unity 패키지입니다.

## 적용

1. Unity에서 Play를 정지합니다.
2. **Assets → Import Package → Custom Package…**에서 **gamescene(5).unitypackage**를 선택합니다.
3. **All → Import**를 누르고 컴파일이 끝날 때까지 기다립니다.
4. **Assets/01.Scenes/kyoungwonTest.unity**를 엽니다.
5. **Tools → Monster → Boss VFX → Validate Imported Encounter**를 실행합니다. 정상 연결이면 Console에 `Boss VFX 검증 완료`가 표시됩니다.
6. Play에서 일반 몹과 보스방 전투를 확인합니다. 프리팹과 프로필은 연결되어 있습니다.

원본 씬도 포함하는 전체 패키지입니다. 별도로 편집한 씬을 유지하려면 Import 목록에서 해당 씬을 해제합니다.

## 보스의 선명도·연출

- 기존 671개 방향·동작 프레임에 어두운 갑옷을 밝히는 셰이더, 선명한 청록 네온 윤곽, 녹색 코어 발광을 적용했습니다. 차징과 타격 시 패턴 색상과 발광 강도가 변합니다.
- 원본 프레임은 Point 필터와 비압축 설정을 사용합니다. 전체 사각 메시로 바꾸고, 서로 다른 크기의 프레임을 피벗과 Pixels Per Unit 기준으로 정렬해 동작 전환 시 모양이 늘어나 보이는 현상을 줄였습니다.
- 새 에너지·충격파·폭발·파편·화염 시트를 실제 ParticleSystem의 수명, 속도, 회전, 색상 변화와 함께 재생합니다. 폭발과 기둥에서 겹치던 큰 스프라이트 섬광을 정리했습니다.
- 30개 패턴의 타격음을 금속 충돌·충격음·저음으로 다시 믹스했습니다. 패턴별 시작·유지·타격·종료 사운드 120개 연결은 유지합니다.

### 애니메이션 연결

- 타격 때마다 공격 클립을 중간부터 다시 시작하던 처리를 제거했습니다. 반복 피해가 발생해도 시전 루프가 이어집니다.
- 준비·시전·회복 72개 클립의 연결 포즈를 맞췄습니다. 회복 클립의 마지막은 해당 방향의 대기 포즈입니다.
- 긴 예고에서는 준비 동작을 최대 0.85초에 재생한 뒤 준비 자세의 루프로 이어집니다. 예고가 끝나도 같은 루프를 재시작하지 않습니다.
- 플레이어를 따라 방향이 바뀌면 동작 진행률을 유지합니다. 짧은 전환 블렌딩은 상태가 바뀔 때만 적용하고 일반 프레임은 선명하게 표시합니다.
- 셰이더의 전환과 몸체의 미세한 호흡·반동은 `BossVisual` 자식에서 처리합니다. 보스 루트와 충돌 크기는 그대로 사용합니다.

### 그림자·발자국

보스 프리팹에 **MonsterGroundPresentation**과 **BossGroundContact**를 연결했습니다. 고정된 발 위치를 기준으로 부드러운 바닥 그림자가 따라오고, 실제 이동 거리마다 좌우 발자국·먼지·묵직한 발소리가 발생합니다. 돌진 중에도 표시하며 잠복, 정지, 사망에는 새 발자국을 만들지 않습니다. 순간 배치 변경은 긴 발자국 줄로 이어지지 않습니다.

설정은 **Assets/08.Data/MonsterPresentation/BossMonsterGround.asset**입니다. 발자국은 3.5초에 걸쳐 사라집니다. `BossGroundContact`의 위치로 발밑 정렬을 조절할 수 있습니다.

## 검증 범위

몬스터 런타임 42개 파일의 Unity 2021.3 API 참조 컴파일, 수정 C# 구문 검사, 애니메이션 검증 8개 그룹, 기존 전투 검증 18개 그룹과 90개 패턴 타임라인을 통과했습니다. 연속 타격 200회에도 시전이 재시작되지 않는 것을 모델에서 확인했습니다. 리소스 GUID·클립 연결·PNG·WAV와 패키지 압축 해제를 검사했습니다. Player 스크립트 17개와 원본 씬은 바이트 단위로 유지했습니다.

이 환경에는 Unity Editor가 없어 **실제 Play 화면, 셰이더 렌더링, 효과음 청취와 프레임 성능은 확인하지 못했습니다.** 가져온 뒤 위 검증 메뉴와 Play에서 최종 전투를 확인하세요.
